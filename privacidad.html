PRIVACIDAD · FUNCIONAMIENTO ACTUAL

Qué datos usa esta herramienta.

Cambio Claro no exige una cuenta y no incorpora analítica ni rastreadores publicitarios. Eso no significa que navegar o consultar fuentes externas sea anónimo.

Preferencias y cálculo local

El comparador guarda la ciudad y la moneda elegidas en el almacenamiento local del navegador, si está disponible, bajo la clave cambio-claro:preferences:v1. Podés borrarlas eliminando los datos de este sitio desde la configuración de tu navegador. Si el almacenamiento está bloqueado, el comparador puede seguir funcionando sin recordar esas preferencias.

El importe, la operación, el canal y la cotización manual no se guardan como preferencias. El cálculo se hace en tu navegador y el importe introducido no se añade a las consultas de cotizaciones. Las lecturas de fuentes se reutilizan temporalmente en memoria; no se guardan como un historial de cotizaciones entre sesiones.

Compartir incluye tu selección

El botón «Compartir selección» genera un enlace que contiene ciudad, moneda, operación, importe y canal. Quien reciba el enlace podrá verlos. Al abrirlo, esa dirección también puede quedar en el historial del navegador y ser visible para el alojamiento o los servicios utilizados para compartirla.

No compartas un enlace con un importe que quieras mantener privado. Para enviar solo el acceso al servicio, usá la dirección del comparador sin parámetros. Un enlace compartido consulta precios de nuevo: no conserva una oferta ni garantiza un precio.

Servicios externos

  • Alojamiento. La página se sirve desde GitHub Pages. GitHub recibe los datos de conexión necesarios para servirla, como la dirección IP. Consultá la declaración de privacidad de GitHub.
  • Consulta de fuentes. El navegador contacta con Jina Reader para leer muchas páginas públicas y con determinadas interfaces públicas de proveedores. Esos servicios reciben datos habituales de conexión y las solicitudes necesarias para obtener la página o cotización. Consultá la información legal y de privacidad de Jina AI y las políticas de cada fuente enlazada.
  • Enlaces oficiales. Al abrir el sitio de un banco, casa de cambio, mapas o GitHub, salís de Cambio Claro. Ese servicio aplica sus propias condiciones y prácticas de datos.

No enviamos el importe de la calculadora a anunciantes. No hay scripts de redes publicitarias, píxeles de seguimiento ni formularios de captación instalados en estas páginas.

Contacto y futuros cambios

Los reportes enviados mediante GitHub Issues son públicos y pertenecen al servicio de GitHub; no son un canal confidencial. Revisá qué información incluir y qué evitar.

Antes de incorporar un servicio comercial o de medición, será necesario revisar su tratamiento de datos y actualizar esta información. La preparación técnica de un espacio publicitario no activa una red ni introduce cookies de anuncios.

Información orientativa, no una oferta de cambio. Confirmá precio, comisiones y disponibilidad con el proveedor.
